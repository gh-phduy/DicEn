# Pronunciation data

The A1 IPA snapshot in `../a1-pronunciations.json` is selected from
[open-dict-data/ipa-dict](https://github.com/open-dict-data/ipa-dict),
`data/en_US.txt`, revision `43c3570eb3553bdd19fccd2bd0091534889af023`.
Source: https://raw.githubusercontent.com/open-dict-data/ipa-dict/43c3570eb3553bdd19fccd2bd0091534889af023/data/en_US.txt

The source project's README identifies its American data as based on the modified
[cmudict-ipa](https://github.com/lingz/cmudict-ipa), with stress markers.
Both MIT notices are included in this directory. The hand-written overrides in
`../../a1-extra.mjs` distinguish homographs, compounds and common weak forms.
The snapshot is broadly phonemic American English; it is not a claim of Oxford
authorship, and actual device voices may realize vowels differently.

Vietnamese glosses, teaching examples, word-family selections, usage notes and
comparisons added for A1 were written for DicEn. Oxford headwords, printed casing,
CEFR and level-specific parts of speech are taken from the user-supplied
`American_Oxford_3000.pdf`. The original PDFs are not included.

Selected grammar checks link to primary references in `../../a1-references.mjs`.
These references support the selected grammar topics; they do not represent a
dictionary-by-dictionary verification of all 899 editorial entries.
